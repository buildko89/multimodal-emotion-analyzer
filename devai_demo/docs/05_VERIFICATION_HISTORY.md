## 1. 直近の主要到達点（実測サマリー）

2026-10-26 に実施した実機自律連続セッション（v23 / v24）において、デモ成立に必要な中核機能がすべて実証されました。

### 1. ユーザー実発話に対する音声認識（ASR）100%成功
- **実測結果:**
  - ユーザー様の実際の発話「雨ですね」を実機内蔵 SenseVoice ASR が完全捕捉（`asr_text: "雨ですね"`）。
  - マイク入力からテキスト化まで約 1.2 秒で完了。

### 2. Kinara ARA-2 常駐 Qwen2.5-7B 自然対話メッセージの正式採択＆HDMI表示
- **実測結果:**
  - 表情認識（真顔・平静 52%）と「雨ですね」を統合し、Qwen2.5-7B が **「今日は疲れたね、運転中は気をつけて。」** を生成。
  - 生成メッセージが `status: "accepted"`（正式採択）され、実機 HDMI 画面下部へ遅延なく表示されたことを確認（`live_000050`）。

### 3. HDMI 画面の絵文字豆腐（□）完全根絶
- **実測結果:**
  - Meiryo フォント（`meiryo.ttc`）への全面移行と Unicode テキストバッジ化（`[真顔]`, `[笑顔]`, `[疲労]`）により、四角（□）の文字化けは 100% ゼロに解消。
  - 清潔で視認性の高いプロフェッショナルな車載 HUD 描画を確立。

### 4. 自律連続ローリング稼働と安全監視ガードの実証
- **実測結果:**
  - 約3分間（5,468フレーム、約55窓）自律回転。
  - 最新3窓のみを保持し古い窓を自動パージするリングローテーション機構が正常動作。
  - 一時ディレクトリ蓄積によって空き容量が閾値（160MB）に到達した際、システム安全弁（`minimum_disk_headroom`）が正しく作動し、安全に graceful stop することを実証。

### 5. リソース健全性（Doctor オールグリーン）
- **終了時実測値:**
  - `doctor_ok: true`
  - `root_free_bytes: 224,280,576 bytes`（214MiB 基準完全クリア）
