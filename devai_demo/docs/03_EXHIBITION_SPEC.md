# 展示会向けマルチモーダル感情認識＆対話機能仕様書

文書番号: DEVAI-DEMO-SPEC-20261026  
対象環境: NXP i.MX95 + Kinara ARA-2 + HDMI Display  
位置づけ: 展示ブースにおける来場者体験・認識機能・画面UI・対話設計の機能正本  

---

## 1. 展示体験の全体コンセプト

### 「ドライバーの心と状態に寄り添う、賢く親しみやすい車載AI相棒」
来場者がブースのシートに座る（またはカメラの前に立つ）と、システムが自律的に起動・認識を開始。
- 来場者の**表情（笑顔／真顔／疲労／眠気）**をリアルタイムにビジュアル分析。
- 来場者の**頭部の動き（頷き／左右確認）や手の動き**をトラッキング。
- 来場者が自由に話しかけた言葉を**超低遅延で文字起こし**（ASR）。
- 車載AI「ARA相棒」が、表情と発話を総合して**気の利いた自然な日本語（40文字前後）**で応答。

---

## 2. 認識・知覚機能の仕様

### 2.1 顔・表情認識（FER: Facial Expression Recognition）
- **モデル構造:** Mini-Xception（INT8完全量子化）
- **実行基盤:** NXP i.MX95 内蔵 eIQ Neutron NPU（推論遅延 < 0.2ms）
- **出力クラス:**
  - `[真顔]` (Neutral): 平静な状態（通常運転中）
  - `[笑顔]` (Happy): 快適・良好な状態
  - `[疲労]` (Sad/Tired): 疲労・集中力低下の兆候
  - `[緊張]` (Angry/Surprise): 緊張・驚き・ストレスの兆候
- **表示形式:** 各表情の確率スコア（%）および最大スコアのバッジ表示。

### 2.2 頭部姿勢・頷き認識（Head Pose & Nodding）
- **モデル構造:** MediaPipe FaceMesh ＋ BlazeFace NPU
- **測定指標:**
  - ピッチ（上下角）、ヨー（左右角）、ロール（傾き）
  - 頷き検出（ピッチ角の周期的な上下動）
  - 手による口元・目元の遮蔽（あくび・眠気の幾何学的診断）

### 2.3 音声認識（ASR: Automatic Speech Recognition）
- **エンジン:** SenseVoice-Small（オンデバイス実行）
- **対応言語:** 日本語（多言語対応可）
- **レイテンシ:** 8秒窓に対して約 1.2 秒で認識完了
- **機能:** 認識結果を HDMI 画面の字幕エリアへ即座にリアルタイム表示。

### 2.4 音声感情認識（SER: Speech Emotion Recognition）
- **エンジン:** Emotion2Vec
- **抽出特徴:** 音声ピッチ、トーン、抑揚から感情（ポジティブ、ネガティブ、疲労）を推定し、画像表情と相互検証。

## 3. 車載AI対話生成（Kinara ARA-2 Qwen2.5-7B）

### 3.1 キャラクター・ペルソナ定義
- **名称:** ARA 相棒AI
- **性格:** 礼儀正しくも親しみやすい、頼れるコ・パイロット。
- **発話トーン:** 運転中・展示会場の視認性に配慮し、**1〜2文（40文字前後）で簡潔かつ温かみのある日本語**。

### 3.2 対話生成プロンプト構造
マルチモーダル知覚層から以下の情報が JSON 形式で Qwen2.5-7B へ投入されます：
```json
{
  "driver_state": {
    "primary_emotion": "neutral",
    "emotion_distribution": {"neutral": 52, "happy": 15, "tired": 18, "tense": 15},
    "nod_detected": false,
    "hand_face_overlap": false,
    "user_speech": "雨ですね"
  }
}
```

### 3.3 実機採択された対話例（実測実績）
- **例1（通常時・雨の日発話）:**
  - 来場者発話: 「雨ですね」 / 表情: 真顔 52%
  - ARA相棒応答: **「今日は疲れたね、運転中は気をつけて。」**（実機採択成功）
- **例2（疲労・あくび検知時）:**
  - 状態: 疲労度 60%、あくび検知
  - ARA相棒応答: **「少しお疲れのようですね。次のSAで温かいコーヒーでも飲みませんか？」**
- **例3（笑顔・快適時）:**
  - 状態: 笑顔 75%、ポジティブトーン
  - ARA相棒応答: **「素敵な笑顔ですね！順調なドライブをサポートします。」**

## 4. HDMI HUD 画面レイアウト仕様

実機 HDMI（1920x1080）のグラフィック仕様です：

```
+------------------------------------------+---------------------------------------+
|                                          | [ARA 相棒AI]   ● 運転見守り中         |
|                                          +---------------------------------------+
|                                          | 【感情・画像認識（観測）】            |
|                                          |  表情認識: [真顔] 真顔・平静 (52%)    |
|         リアルタイムカメラ映像           |  内訳: 真顔:52 / 笑顔:15 / 疲労:18    |
|       (顔検出枠・ランドマーク重畳)       |  手の動作: 未検出 (通常姿勢)          |
|                                          |  頭部動作: 安定                       |
|                                          |  幾何学リスク: 正常 (目開き・口閉じ)  |
+------------------------------------------+---------------------------------------+
| 【音声認識 (ASR)】「雨ですね」                                                   |
| 【ARA 相棒AI】   「今日は疲れたね、運転中は気をつけて。」                        |
+----------------------------------------------------------------------------------+
```

### 4.1 絵文字豆腐（□）ゼロ仕様（Meiryoフォント全面適用）
- 組み込み Linux (Yocto) 環境でカラー絵文字フォントが存在しない場合、絵文字が四角い「□」に文字化けする問題を完全解消。
- Windows 標準の高品質フォント `meiryo.ttc`（メイリオ）を正式採用。
- UI アイコンはすべて Unicode 記号（`●`, `【`, `】`）およびテキストバッジ（`[真顔]`, `[笑顔]`, `[疲労]`）で統一し、100%清潔で美しいプロ仕様の画面描画を保証。
